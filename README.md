# Gaze-Adaptive VR Streaming for Remote Operation of Autonomous Ferries

Streams a ferry's cameras in full quality only where the remote operator looks (eye tracking in a VR headset), so immersive 360° VR supervision fits through narrow ship-to-shore links. Part of **CAPTN**, Kiel.

Project page: https://kainat-altaf-cau.github.io/adaptivegaze/
